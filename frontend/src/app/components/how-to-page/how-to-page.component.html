How QuantLedger Works

The Goal

QuantLedger is an algorithmic backtesting engine designed to track complex trading data using a transactional Postgres database. It allows quantitative researchers to configure text-based trading rules and simulate them against market data.

1. Creating Strategies

A Strategy maps an Owner, a Stock Ticker, an initial capitalization budget, and two core rules:

  • Buy Rule: Conditions under which the algorithm purchases shares (e.g., "PRICE <= 50 AND RSI < 30").
  • Sell Rule: Conditions under which the algorithm dumps shares (e.g., "PRICE >= 100").

2. Running Simulations (Randomized MVP)

When you generate a Backtest Report, the backend parses that strategy and tests it across historical data.

Important Note: For the purposes of this MVP Database Demo, our backend Java engine executes randomized algorithm behavior (random trades and volatility). This guarantees the Trade Ledger and Simulations tables are filled with dynamic, volatile data so we can test the database aggregates accurately.

This is why running the same strategy simulation multiple times produces different results! You are simulating a stochastic market environment.

3. The Trade Ledger

Every mock execution is recorded meticulously into the Trade_Ledger table, preserving a perfect transaction audit trail of all actions the engine took.
